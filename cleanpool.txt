#  CLEANPOOL — Configuración de productos
#  (página: cumuloingenieria.com.ar/Cleanpool/)
# ============================================================
#
# Este archivo se edita directamente en GitHub (ícono del lápiz)
# y la página lo lee sola: no hace falta tocar el HTML.
# Los cambios pueden tardar unos minutos en verse.
#
# CÓMO CAMBIAR O AGREGAR FOTOS:
#   1. Subí las fotos a la carpeta "cleanpool" del repositorio:
#      https://github.com/cumulorosario/cumulo-imagenes
#   2. En "fotos" poné los nombres de archivo separados por coma.
#      La primera foto es la principal.
#
# CÓMO AGREGAR UN PRODUCTO NUEVO:
#   Copiá un bloque [producto_XX], cambiá el número y completá los campos.
#   Los productos aparecen en el orden en que están en este archivo.
#   Los campos que no uses se pueden borrar.
#
# FORMATO DE LOS CAMPOS:
#   descripcion     → para un párrafo nuevo, empezá la línea siguiente
#                     con dos espacios (como en los ejemplos).
#   versiones, caracteristicas, incluye, montaje, aclaraciones
#                   → elementos separados con el signo |
#   versiones       → formato  Nombre: detalle | Nombre: detalle
#   whatsapp_texto  → mensaje con el que se abre WhatsApp al tocar "Consultar".
#   destacado       → etiqueta sobre el producto (ej. "Más vendido"). Los productos con
#                     este campo también aparecen en "Los más elegidos", arriba de todo.
#
# SELECTOR DE OPCIONES Y PRECIO (opcional, por producto):
#   opcion_1  = Título: valor | valor | valor     (botones para elegir; podés sumar opcion_2, opcion_3...)
#   precios   = seccion, seccion                  (secciones de precios.txt que se suman)
#   precio_nota = texto chico debajo del precio
#   cantidad  = 10                               (agrega un selector de cantidad, de 1 al número indicado)
#   En "precios", una sección con "x cantidad" se multiplica por la cantidad elegida
#   (ej. "precios = luz_fibra x cantidad, accesorios": la luz se multiplica y los accesorios se suman una vez).
#   En cada sección de precios.txt se usa el precio del valor elegido
#   (ej. "Mavi = ..." o "Ø 25 mm x 80 mm = ..."); si no está, se usa "precio".
#   La selección y el precio se agregan solos al mensaje de WhatsApp.
#
# Para ocultar un producto sin borrarlo, poné:  oculto = si
# ============================================================
